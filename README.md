# Каскад · 2048

Лабораторная работа №3 по веб-программированию. «Каскад» — игра на поле 4×4 с последовательными слияниями плиток, реализованная на HTML, CSS и JavaScript.

## Как играть

Управляй плитками стрелками на клавиатуре или экранными кнопками. Одинаковые плитки объединяются и добавляют очки за каждое слияние. Например, четыре плитки со значением 4 сначала образуют две плитки по 8, а затем одну плитку 16. За такой ход начисляется 32 очка.

Можно отменить один ход или начать новую партию. Поле, счёт и доступный шаг отмены восстанавливаются после перезагрузки. Когда возможные ходы заканчиваются, результат можно сохранить под своим именем. Таблица показывает десять лучших результатов с датами их сохранения в этом браузере.

## Запуск локально

Из корня репозитория запусти локальный сервер и открой игру в браузере. Сборка и установка зависимостей не требуются.

```sh
python3 -m http.server 8000
```

[Открыть игру локально](http://localhost:8000/)
